# Video originals

The individual source clips in `video/` are kept here because they are not part of
the deployed site. `public/` has a 60 MB hosting limit, and the deployed film is the
combined montage in `public/media/video/home-hero-montage-*.mp4`.

These files are byte-identical to the originals. Move a clip back into
`public/media/video/` only if a page starts using it again.
